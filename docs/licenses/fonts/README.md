# Bundled fonts

All three families are under the SIL Open Font License 1.1 (full texts beside this
file) and were downloaded from https://github.com/google/fonts (`ofl/` folder) on
2026-10-14. They live in `shared/ui/src/commonMain/composeResources/font/`. The OFL
lets us bundle them in the apps; it requires shipping the license text, so the About
screen must list them (DESIGN 9.9).

| File | Family | Use (DESIGN 4) |
|---|---|---|
| `atkinson_hyperlegible_regular.ttf`, `atkinson_hyperlegible_bold.ttf` | Atkinson Hyperlegible 1.006 | Body text and all data |
| `fredoka_variable.ttf` | Fredoka (variable wdth/wght) | Kid display, used at weight 600 |
| `barlow_semi_condensed_bold.ttf` | Barlow Semi Condensed | Adult display, weight 700 |
