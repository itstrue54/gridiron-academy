# Level 5: items for football review

Validator-clean and rendered; these need a coach's sign-off before release.

## Terminology that varies

| Step | Claim | Note |
|---|---|---|
| `c5-subs-03`, glossary `dime` | Nickel is five defensive backs, dime six; names for seven-back packages vary. | "Quarter" and "dollar" mean different things on different staffs, so the content doesn't define them. Decide whether to teach one convention at Level 6. |
| `c5-subs-01` | Nickel is the most common NFL defense. | True for years; re-check if usage shifts. |
| `c5-protect-01..04` | Slide, Mike ID, hot, sight adjust and max protect as described. | Protection language is very system-specific; these are the common meanings. |
| `c5-pressure-01..03` | Fire zone = five rushers with three deep and three under; creeper = four rushers from unexpected spots. | Some staffs use "fire zone" for any zone blitz. |
| `c5-motion-*` | Jet, orbit, return and across motion as drawn. | Names are common but not universal ("zip", "rip/liz", "yo-yo"). |
